How I work

Documentation philosophy

Great documentation isn't just about accuracy. It's about empathy, clarity, and reducing friction at every step. Learn more about my style →

Reduce time-to-success

I reduce time-to-success by building working applications myself. If I can't make it work, developers won't either. I identify and eliminate friction points through support case patterns and documentation feedback.

Build exceptional teams

I hire and develop writers who care about craft. My teams consistently deliver under pressure because I focus on removing roadblocks and creating systems that work.

Leverage AI thoughtfully

I build AI tools that scale content production without sacrificing quality. Technology should augment human expertise, not replace the careful thinking behind great docs.

My style philosophy

I serve up content with translation-ready clarity. I address developers directly as collaborators, front-load critical information, and trust reader intelligence. Every sentence earns its place by reducing friction and accelerating time-to-success.

Explain the why, not just the what
✗ Don't
Set timeout to 30.
✓ Do
To reduce the risk that a long-running query blocks other operations, set timeout to 30.
Front-load critical information
✗ Don't
This release includes several improvements to performance and adds new features. Note that the authentication method has changed and is not backward compatible.
✓ Do
Version 3.0 breaks backward compatibility with the authentication method. Before you upgrade, migrate to OAuth 2.0.
Anticipate the next question
✗ Don't
Enable caching to improve performance.
✓ Do
To improve performance, enable caching. If your data changes frequently, set cache_ttl to 60 seconds or less to prevent stale results.
Trust technical competence
✗ Don't
A database is a system that stores data. Configure your database connection string, which is the text that tells your application where to find the database.
✓ Do
Configure your connection string to point to the primary replica. Use the secondary replica only for read operations.
Every word earns its place
✗ Don't
In order to successfully complete the process, it is essential that you ensure the connection is active.
✓ Do
Before you start, verify that the connection is active.
Optimize for translation
✗ Don't
Verify the file contains valid JSON using the validator.
✓ Do
Use the validator to verify that the file contains valid JSON.
