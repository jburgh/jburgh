style.config

My style philosophy

My content follows the Google Developer Documentation Style Guide, emphasizing conditions-first sentence structure, translation-ready clarity, and precise technical specifications. I address developers directly as collaborators, front-load critical information, and trust reader intelligence. Every sentence earns its place by reducing friction and accelerating time-to-success.

Voice: Knowledgeable colleague
✗ Don't
Please note that it is important for the user to configure their settings appropriately.
✓ Do
Configure your settings before you deploy.
Front-load critical information
✗ Don't
After you've set up your environment and configured the basics, you'll want to know that the API rate limit is 1000 requests per hour.
✓ Do
The API rate limit is 1000 requests per hour. Configure your retry logic accordingly.
Conditions before actions
✗ Don't
Choose Submit to save your changes when you finish your edits.
✓ Do
When you finish your edits, choose Submit to save your changes.
Optimize for translation
✗ Don't
Verify the file contains valid JSON using the validator.
✓ Do
Verify that the file contains valid JSON. Use the validator to check syntax.
Eliminate gerunds in headings
✗ Don't
Configuring clusters using templates
✓ Do
Configure clusters that use templates
Strong verbs over weak constructions
✗ Don't
Perform configuration of the database. Utilize the dashboard to facilitate implementation.
✓ Do
Configure the database. Use the dashboard to create the implementation.
Technical precision with versions
✗ Don't
This feature is available in recent versions.
✓ Do
This feature is available in EMR 6.1.0 and later. For EMR 5.x, see Legacy configuration.
Explain parameters at first use
✗ Don't
Set the MAX_RETRIES parameter. The default value is documented elsewhere.
✓ Do
Set the MAX_RETRIES parameter. The default value is 3. Values above 10 might cause timeout errors.
State goals before actions
✗ Don't
Run npm install and then npm build.
✓ Do
To prepare your application for deployment, run npm install and then npm build.
Every word earns its place
✗ Don't
In order to successfully complete the process, it is absolutely essential that you ensure the connection is active.
✓ Do
Before you start, verify that the connection is active.
